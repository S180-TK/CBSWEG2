# CBSWEG2 MCO4: Midpoint Presentation & Automated Testing Demo

_De La Salle University Manila — College of Computer Studies, Software Technology Department_

Implement and demonstrate automated unit testing on your AI/ML application. Automated testing should be performed in GitHub Actions and must proceed without any manual intervention, aside from the git command that triggers the test workflow.

## Slide Deck Requirements

Prepare and present a slide deck containing the following:

- **Project Overview**
  - Dataset
- **Member Roles and Responsibilities**
- **Technical Requirements**
- **Unit Tests**

## Live Demo

After the presentation, you will do a live demo of your automated testing. During the demo, you will be asked to:

- **Introduce a bug** into one of your modules and push the change to a test branch
  - The automated tests should trigger automatically
  - Expected outcome: failed test run
- **Fix the bug** (revert to the previous working code) and push the updated code
  - All unit tests should run
  - Expected outcome: successful test run
- **Show that the code you tested is the same code** used in your Jupyter Notebook

## Time Limit

The presentation and demo should be within **15 minutes** in total.
